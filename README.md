# LashKStudio Website

This is a Vercel-ready static website for LashKStudio.

## Deploy
1. Upload this folder to GitHub.
2. Go to Vercel > Add New Project.
3. Import the GitHub repo.
4. Click Deploy.

## Update booking link
All booking buttons currently go to:
https://lashkstudio.square.site

## Replace photos
Put new images in the `assets` folder and update the matching image filenames in `index.html`.
